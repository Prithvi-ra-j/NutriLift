## 📝 Documentation Guidelines

### When to Create New Docs

- **Major features** - Create dedicated guide
- **Breaking changes** - Update migration docs
- **New workflows** - Create step-by-step guide
- **Bug fixes** - Add to changelog (not separate doc)

### When to Archive Docs

- **Outdated information** - Move to archive
- **Superseded by new docs** - Move to archive
- **Historical reference only** - Move to archive

### Documentation Best Practices

1. **Keep it current** - Update docs when code changes
2. **Be specific** - Include code examples and commands
3. **Be concise** - Get to the point quickly
4. **Use structure** - Headers, lists, code blocks
5. **Link related docs** - Help users navigate
